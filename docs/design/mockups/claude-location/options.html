Where Claude is: four ways to mark it

The card keeps the launch directory and its branch. The shell and the docs reader open there too. When Claude has moved somewhere else (a cd, an /add-dir directory, EnterWorktree), a marker appears and hovering it says where Claude is now. Each option below shows a session still in its launch directory, then one that has moved into a worktree, on the three surfaces that carry the repo line: the rail card, the Focus header and the tile header. The tooltip is drawn statically under the moved card. In the app it is the native hover title.

Open questions

When does the marker show? Claude's Bash tool often runs cd web && npm test, and the shell stays in web/ afterwards. If any difference shows the marker, it will be on most cards most of the time. The alternative is to show it only when Claude is in a different checkout: a worktree, or another repo added with /add-dir. A subdirectory of the launch directory would not count.

Keyboard and screen readers. In every option the marker also carries an aria-label with the same text as the hover, so the information never depends on a mouse.
