Rules this mockup proposes

  • Truncation is at the end, with an ellipsis, on every surface. Nothing wraps.
  • Focus header and rail card wrap at the /: the folder (with its trailing slash) on one line, the branch on the next. Each line truncates on its own, so a long branch never hides the folder or the model.
  • Focus header: hovering the folder/branch block shows the full launch folder, its branch and path, and where Claude is when it has moved.
  • Rail card: the repo block and the ↳ block keep their own hover. Compact density keeps repo / branch on one line, as today.
  • ↳ appears only when Claude is in a different checkout from the launch directory (a worktree, or another repo via /add-dir), never for a cd inside the launch checkout.
  • Tile header: one repo line plus the ↳ glyph when moved. The hover matches the Focus header.
  • The ↳ line and glyph use neutral colours only, never a state colour (design-system §3), and carry an aria-label with the hover text.
