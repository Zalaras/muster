Mockup — not a working app. Overview state comes from Notification / Stop / TeammateIdle hooks keyed on CLAUDE_SESSION_ID. The lead panel uses ListAgents and SendMessage, plus CLAUDE_CODE_MESSAGING_SOCKET to post into a session from outside. Grid panes are tmux capture-pane rendered in xterm.js — sessions must be launched by Relay to appear here. Usage comes from the status line's stdin payload (rate_limits, cost, context) plus the OTel exporter; costs are estimates. Permissions use a PermissionRequest HTTP hook for live decisions, an MCP tools/list call for the tool inventory, and a deterministic JSON merge into settings.json.
