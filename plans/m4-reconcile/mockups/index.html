Common to every option (already decided this session)

  • Tiles → tiles-dead.html. The tile footer already acts as the tile's own header bar, so tiles are the same in A/B/C: live footer gains End; a dead tile shows its last snapshot under an ended cap and swaps its geometry readout for Resume / Remove; strip cards for ended sessions carry the same pair.
  • Confirm dialogs for both End and Remove (buttons bottom-right on each page show them). End's copy says the session is recoverable via Resume — Muster already holds the Claude session id from the envelope, which is exactly the hash claude prints on exit, so nothing needs to read the pane.
  • Remove only when ended (shown greyed / absent on live cards). Overrule if you want Remove-on-live; the dialog would then say "ends the session first".
  • Last snapshot: an ended session's final screen is shown dimmed with an ended cap and a thin status bar ("ended 6m ago · last state failed · last captured screen, not a live client"). Captured every liveness tick (~5 s) for live sessions, so the snapshot is at most ~5 s before death.
  • Ended card in the rail: dashed stripe, dimmed, name struck through, timer reads ended 6m; the state badge keeps the last known state (alive is orthogonal to state — protocol §7.5).
