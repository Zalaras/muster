C — Effort as a stepped meter

effort · option C ·  dashed  = new

Effort is a five-step meter from faster to smarter, echoing Claude Code's own /effort slider; the steps fill up to the chosen level. Ticking use Claude Code's default greys the meter out and sends no flag. A launch mismatch adds a second row inside the header itself, under a dashed rule, with a quiet dismiss link.
