A — Effort as another segmented row

effort · option A ·  dashed  = new

Effort gets its own row under Model, with the same segmented control as Model and Start in. default sends no flag. The header shows the level in brackets in the model's own colour. A launch mismatch puts a full-width warning strip under the header, in a new yellow warning colour (not amber, which means needs-you, and not the red danger banner). While it shows, the effort in the header takes the same colour; Dismiss removes the strip and the effort returns to its normal colour. Try it below.
