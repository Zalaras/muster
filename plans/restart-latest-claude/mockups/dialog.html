Restart onto the new Claude Code: the confirm dialog

One dialog for every notice option. It lists what happens to each live session that runs an older version. A session restarts now only when it is idle with no background tasks, or failed. Every other one is queued and restarts the moment it next becomes idle with no background tasks, with the reason shown: working, planning, waiting on you, or idle with background tasks. Stopped sessions are not listed; they pick up the new version on their next Resume. A session in plan mode is called out because a resume brings it back in default mode (kb:fact/resume-restores-model-and-mode-except-plan). Each restart keeps the session's row, title, group, rail position, conversation and effort.
