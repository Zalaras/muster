  module through (`web-implementation-W3.md`'s Decisions: "no barrel").
- `docs/features/connection/spec.md`'s `web:` glob: dropped the stopgap
  `web/src/protocol.test.ts` entry now that the file is gone and `web/src/protocol/**`
  covers the 7 replacement files. `make gen-kb` regenerated `.claude/rules/connection.md`
