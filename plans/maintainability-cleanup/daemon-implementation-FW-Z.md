## Decisions

- design: `closeShutdown` is a small package-level function beside `errRegistryClosed`, matching the file's existing pattern of small shared helpers next to the type they serve (`clampInt`, `logUnknownTextFrame`, `applyResize` all sit this way in the same file). `rg -n 'func close' internal/server/terminal.go` showed no existing helper doing this before I added it.
- design: `notFound()` dropped its parameter rather than gaining a second no-arg constructor, since `rg -n 'notFound\(' internal/server/*.go` (excluding `_test.go`) shows exactly one call site and it always passed the same text — keeping the parameter would have kept inviting a second, divergent spelling at some future call site. `notResumable`/`directoryMissing` keep their `message string` parameter unchanged: each has multiple call sites with genuinely different text (`launcher.go:379,382,385`), which is the documented reason `writeDirectoryMissing`'s own comment already gives for not merging with `directoryMissing`.
- No REQs apply here — this is a fix-wave residue task (specific rows from `review.maintainability.fixwave.md` and `review.work.cycle2.md`), not new plan REQs.
