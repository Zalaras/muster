## Holds

Held as written, and wider: every close the developer triggers from the panel or glyph — Escape
(anchored and popped), the popped panel's close button, and a second glyph click — lands focus on
the `Note` glyph button, not the terminal. Only click-away (anchored) already ends in the terminal,
because the click itself puts focus there.

## Cause

`web/src/features/notes.ts:195-208` — `close(returnFocus)` ends with
`if (returnFocus || hadFocus) glyph.focus(...)` (line 207), and `closeByUser()` (line 210), reached
from Escape via `leaveOrClose()` (line 267, handler `onEscape` line 109), the close button
(`onClose`, line 106) and the glyph toggle (line 297), always passes `returnFocus = true`. It is
the return-to-opener pattern `render/menu.ts:138` and `render/diagramdialog.ts:126` use; the
notes controller has no handle on the terminal — `initNotes(app)` (line 48) takes no deps, so it
cannot call `surfaces.focusSelected(id)` the way `rail.ts:193` and `launch.ts:845` do.

## Questions

1. **Which closes return to the terminal?** The issue names Escape. The popped close button and
   a second glyph click currently also go to the glyph. Proposed default: all three user closes go
   to the terminal (consistent with kb:adr/focus-rail-click-focuses-terminal for a pointer). The
   alternative keeps the glyph for a *keyboard* toggle of the glyph (Enter/Space), the usual
   disclosure-button convention the menus and diagram dialog follow.
2. **Which surface when Shell or Docs is showing?** Proposed default: the selected surface —
   `surfaces.focusSelected` focuses the shell terminal when Shell is selected; with Docs selected
   or an ended session (no terminal), fall back to the glyph so focus never drops to `body`.
   Alternative: always Claude's terminal regardless of selection (would need switching surfaces —
   not recommended).

Tiles view: not applicable — the anchored panel closes on leaving Focus and the popped one is
hidden in Tiles, so no close by Escape/button happens there. No convention in
`docs/conventions.md` covers focus-on-close; no ADR is reversed.


## Answers

Developer, verbatim (2026-10-22): "2 confirmed." / "Ok drop 3 from this batch" / "The other’s I didn’t mention we’re going with your suggested default"

Go, defaults:
- 4a: Escape, the popped panel's close button and a second click on the note glyph all return focus to the terminal.
- 4b: focus goes to the selected surface (surfaces.focusSelected), so the shell terminal when Shell is selected. With Docs showing or the session ended, it falls back to the note glyph, never body.
